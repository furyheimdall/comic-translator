Self-hosted manga translation Server v0.5.0

Japanese manga, lettered in Korean.

Upload pages to your own server or read a web chapter with the companion Chrome extension. The server detects Japanese text, removes it, translates the dialogue and places Korean text on the image.

01 / Uploaded chapters

Check the translation against the page it came from.

Upload images, a ZIP/CBZ, or a PDF. Jobs run in a queue on the server; the web app shows progress and logs while the server keeps working. Open the original and the result in the comparison viewer, then download the pages as a ZIP/CBZ.

02 / Reading on the web

Use the server from a manga page.

The separate comic-translator-extension sends eligible images to your server and displays the returned PNG in place. Live translation uses Koharu. Follow these steps once, then translate individual images or the current site.

  1. Prepare the server

    Install the server, prepare a Koharu model under 모델 준비 (Model preparation), and connect an LLM provider in the server web UI.

  2. Load the extension

    Download the extension release ZIP, extract it, then load its folder via chrome://extensions → Developer mode → Load unpacked. Chrome 120+ is required.

  3. Connect the two

    In the extension popup, open 설정 열기 (Settings). Enter the address reachable from this browser and choose 페어링 요청 (Request pairing). Compare its six-digit code with 확장 프로그램 → 연결 요청 (Extensions → Requests) in the server UI, then approve it within five minutes. A passwordless local server only needs a connection test.

  4. Pick translation settings

    Choose a connected provider, model and supported reasoning level in the extension's Settings, then select 설정 저장 (Save settings). The choices come from the server.

  5. Translate as you read

    Right-click an image → 이 이미지 번역 (Translate this image), or enable 이 사이트 번역 (Translate this site) in the extension popup. Use 원본 보기 / 번역 보기 to switch what is displayed.

When the server is on another computer, use that computer's LAN IP and configured port, not localhost. A default install listens on 127.0.0.1:8710 and cannot be reached from another device; the LAN setup guide explains the required host binding and login password.

03 / Get started

Install on a Linux server.

Python 3.12+, uv and engine prerequisites are needed. The installer prepares a local user service but does not start or enable it by default. The source archive does not contain models, fonts or a GPU engine.

Read prerequisites and installation options ↗

Local setup · default 127.0.0.1:8710

git clone https://github.com/furyheimdall/comic-translator.git
cd comic-translator
python3 scripts/install.py --engine koharu
systemctl --user start comic-translator

Open the server web UI, prepare the chosen model, and connect your LLM provider before sending pages. For other machines on your LAN, follow the password-protected LAN installation instructions instead.

Memory planning

The installer minimum is not your working headroom.

The installer checks currently available memory before installing an engine. The recommended figures below are planning allowances for the default models, not measured guarantees that every GPU and model combination will run.

Available memory by engine (GiB)
GPU memoryEngineInstall minimum freeRecommended free
Dedicated VRAMKoharu816
Dedicated VRAMMT / both1624
GB10/GH200 unified memoryKoharu1224
GB10/GH200 unified memoryMT / both2432

MT means MangaTranslator. Dedicated VRAM means free space on one GPU; unified memory means the CPU/GPU-shared system's MemAvailable. You cannot pool separate GPUs' VRAM or add host RAM to a dedicated GPU's VRAM. Budget separately for a local LLM or optional FLUX models.

On the actual server. Translation has been checked on a DGX Spark (GB10) with 128 GB of unified memory. One completed Koharu job coincided with a roughly 10 GiB change in available system memory. On 2026-10-13, with the translator stopped, a local LLM process used about 93.7 GiB of GPU memory; system available memory was about 14.6 GiB and swap usage about 8.9 GiB. This was not a simultaneous LLM-and-translation measurement. It clears Koharu's 12 GiB installation minimum but misses the 24 GiB recommended headroom. Use an external LLM or a smaller local model to leave more room.
