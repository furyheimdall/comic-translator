01 / 원고 업로드

원본과 번역본을 한 쪽씩 비교하세요.

이미지 여러 장이나 ZIP/CBZ, PDF를 올릴 수 있습니다. 서버는 작업을 순서대로 처리하고, 웹 화면에서 진행 상황과 로그를 확인할 수 있습니다. 번역을 마치면 같은 쪽의 원본과 결과를 비교한 뒤 ZIP/CBZ로 내려받으세요.

첫 번역 안내 읽기 ↗
01

자동 번역 결과 확인

뷰어에서 같은 쪽의 원본과 번역본을 전환하며 대사와 글자 크기를 대조하세요. 작은 신문 글씨·손글씨·간판·효과음 일부는 누락되거나 원문이 남을 수 있습니다.

02

번역 엔진과 LLM 선택

파일 번역에는 Koharu와 MangaTranslator 중 하나를 선택합니다. LLM은 별도로 실행 중인 로컬 OpenAI 호환 서버나 지원하는 외부 제공자에 연결합니다. MangaTranslator는 첫 사용 때 추가 모델을 내려받을 수 있습니다.

03

필요한 쪽만 다시 번역

실패하거나 끝나지 않은 쪽만 다시 처리할 수 있습니다. 엔진과 옵션이 같다면 저장된 전처리 결과를 이용해 다른 LLM으로 재번역할 수도 있습니다.

02 / 웹페이지에서 읽기

웹페이지의 만화도 번역합니다.

별도 저장소의 comic-translator-extension을 설치하면 웹페이지의 만화 이미지를 내 서버로 보내고, 받은 번역 PNG를 원본 자리에 표시합니다. 실시간 번역은 Koharu 엔진만 지원합니다.

  1. 서버 준비

    서버를 설치하고 웹 UI의 모델 준비에서 Koharu 모델을 준비하세요. LLM 제공자도 연결해야 합니다.

  2. Chrome 확장 설치

    확장 프로그램 릴리즈 ZIP을 지우지 않을 폴더에 풉니다. Chrome 120 이상에서 chrome://extensions → 개발자 모드 → 압축해제된 확장 프로그램 로드를 눌러 manifest.json이 있는 폴더를 선택하세요. Chrome에는 만화 번역 · 내 서버라는 이름으로 표시됩니다. 설치 후 폴더를 옮기거나 지우면 확장이 사라집니다.

  3. 6자리 코드로 페어링

    확장 팝업의 설정 열기에서 서버 주소를 입력하고 페어링 요청을 누릅니다. 서버 웹 UI의 확장 프로그램 → 연결 요청에서 코드를 대조한 뒤 5분 안에 승인하세요. 비밀번호 없는 로컬 서버는 페어링 대신 연결 테스트만 하면 됩니다.

  4. 번역 설정 저장

    서버가 제공하는 목록에서 번역 제공자·모델·추론 수준을 고르고 설정 저장을 누릅니다. 지원하지 않는 추론 수준은 목록에 표시되지 않습니다.

  5. 원하는 이미지 번역

    한 장만 번역하려면 이미지에서 오른쪽 클릭 → 이 이미지 번역을 선택하세요. 지금 보는 사이트를 번역하려면 팝업의 이 사이트 번역을 켭니다. 원본 보기 / 번역 보기로 화면 표시를 바꿀 수 있습니다.

서버가 다른 컴퓨터에 있다면 확장에는 그 컴퓨터의 LAN IP와 실제 포트를 입력하세요. 기본 설치 주소 127.0.0.1:8710은 서버 컴퓨터에서만 접속됩니다. LAN에 공개하려면 설치 시 바인딩 주소를 0.0.0.0으로 설정하고 로그인 비밀번호를 지정해야 합니다. 0.0.0.0은 접속 주소가 아닙니다. LAN 설치 안내

03 / 시작하기

Linux 서버에 설치합니다.

Python 3.12 이상과 uv, 엔진별 의존성이 필요합니다. 설치기는 systemd 사용자 서비스를 등록하지만 별도 옵션 없이는 시작하거나 자동 시작을 켜지 않습니다. systemd 사용자 서비스나 세션 버스가 없다면 --no-systemd로 설치해 수동 실행기로 실행하세요. 소스 패키지에는 모델·폰트·GPU 엔진이 들어 있지 않으며, 선택한 엔진은 설치 과정에서 받아 설치합니다.

GPU 번역을 실제 확인한 조합은 Ubuntu 24.04/aarch64, NVIDIA GB10(DGX Spark), 드라이버 580, CUDA 13.0입니다. 다른 Linux·GPU 조합에서도 설치는 시도할 수 있지만 엔진 실행은 별도 검증이 필요합니다.

지원 환경과 준비물 확인 ↗

로컬 설치 · 기본 127.0.0.1:8710

git clone https://github.com/furyheimdall/comic-translator.git
cd comic-translator
python3 scripts/install.py --engine koharu
systemctl --user start comic-translator

서버 웹 UI에서 모델을 준비하고 LLM 제공자를 연결한 뒤 원고를 올리세요. 다른 기기에서 접속하려면 설치 시 바인딩 주소를 0.0.0.0으로 두고 로그인 비밀번호를 설정해야 합니다.

메모리 사양

번역 전에 남겨 둘 메모리

표의 설치 최소치는 엔진 설치 전에 현재 가용 메모리와 비교하는 값입니다. 부족하거나 확인할 수 없다면 웹 앱만 설치하는 --engine none 외에는 진행하지 않습니다. 권장 여유는 기본 모델로 번역하기 전에 확보할 계획값이며, 모든 GPU·모델의 실행을 보장하지는 않습니다.

설치 최소치와 번역 전 권장 여유 (GiB)
GPU 메모리엔진설치 최소 여유권장 확보 여유
전용 VRAMKoharu816
전용 VRAMMT / 둘 다1624
GB10·GH200 통합메모리Koharu1224
GB10·GH200 통합메모리MT / 둘 다2432

MT는 MangaTranslator의 약자입니다. 전용 GPU는 한 장의 남은 VRAM을 확인하고, GB10·GH200은 CPU와 GPU가 공유하는 시스템 메모리의 MemAvailable을 확인합니다. 여러 GPU의 VRAM을 합치거나 전용 VRAM에 시스템 RAM을 더할 수는 없습니다. 로컬 LLM이나 추가 FLUX 모델을 함께 실행한다면 그 메모리도 확보해야 합니다.

실제 검증 장비. 128 GB 통합메모리의 DGX Spark(GB10)에서 완료된 Koharu 작업의 가용 메모리가 약 10 GiB 변동했지만, 작업의 최대 메모리 요구량을 잰 값은 아닙니다. 2026-10-13에는 번역 서비스를 실행하지 않은 상태에서 로컬 LLM만 GPU 메모리 약 93.7 GiB를 사용했고, 시스템 가용량은 약 14.6 GiB, 스왑 사용량은 약 8.9 GiB였습니다. 당시 시스템 가용량은 Koharu 설치 최소치 12 GiB를 넘었지만 권장 여유 24 GiB에는 못 미쳤습니다. 로컬 LLM을 함께 쓰려면 모델의 메모리 사용량을 더해 권장 여유가 남는지 먼저 확인하세요.

확장 릴리즈 ↗

번역할 권한이 있는 콘텐츠에만 사용하세요. 올린 원고와 확장이 보낸 웹페이지 이미지는 서버에서 처리하며, 연결한 OCR·비전·외부 LLM 서비스에 따라 글자나 이미지가 외부로 전달될 수 있습니다. LAN에서 HTTP를 쓰면 로그인 정보와 페어링 토큰, 전송 이미지가 암호화되지 않습니다. 신뢰할 수 있는 내부망에서 사용하고, 외부에서 접속할 때는 VPN이나 HTTPS를 설정하세요. 서버를 인터넷에 직접 공개하지 마세요. 확장은 웹페이지의 이미지 요소(<img>)를 대상으로 하며 CSS 배경만 쓰는 이미지, canvas 전용 뷰어, 브라우저 PDF 뷰어에는 적용되지 않습니다. 이 페이지는 안내용이며 번역은 서버에서 실행됩니다.
