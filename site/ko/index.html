01 / 원고 업로드

번역한 쪽을 원본 쪽과 비교하세요.

이미지 여러 장, ZIP/CBZ, PDF를 업로드합니다. 서버가 작업을 차례로 처리하고 웹 화면에 진행 상태와 로그를 보여 줍니다. 비교 뷰어에서 원본과 번역본을 확인한 뒤 ZIP/CBZ로 내려받을 수 있습니다.

첫 번역 안내 읽기 ↗
01

같은 쪽에서 원본과 결과 비교

대사와 글자 크기를 확인하고 필요한 부분을 검토합니다. 작은 글씨나 효과음 일부는 인식되지 않을 수 있습니다.

02

엔진과 번역 제공자 선택

파일 작업에는 Koharu 또는 MangaTranslator를 사용합니다. LLM은 로컬 OpenAI 호환 서버나 지원하는 외부 제공자에 연결합니다.

03

필요한 쪽만 다시 처리

실패·미완료 쪽을 재시도하거나, 같은 엔진 옵션의 전처리 결과를 재사용해 다른 LLM으로 다시 번역합니다.

02 / 웹페이지에서 읽기

확장 프로그램을 내 서버에 연결합니다.

별도 저장소의 comic-translator-extension이 웹페이지의 이미지 파일을 서버로 보내고, 돌아온 번역 PNG를 그 자리에 표시합니다. 실시간 번역은 Koharu 엔진을 사용합니다.

  1. 서버 준비

    서버를 설치하고 웹 UI의 모델 준비에서 Koharu 모델을 준비합니다. LLM 제공자도 연결합니다.

  2. Chrome 확장 설치

    확장 프로그램 릴리즈 ZIP을 받아 압축을 풉니다. Chrome 120 이상에서 chrome://extensions → 개발자 모드 → 압축해제된 확장 프로그램 로드로 폴더를 선택합니다.

  3. 6자리 코드로 페어링

    확장 팝업의 설정 열기에서 서버 주소를 입력하고 페어링 요청을 누릅니다. 서버 웹 UI의 확장 프로그램 → 연결 요청에서 코드를 대조하고 5분 안에 승인합니다. 비밀번호 없는 로컬 서버는 페어링 대신 연결 테스트만 하면 됩니다.

  4. 번역 설정 저장

    확장 설정에서 연결된 제공자와 모델, 지원하는 추론 수준을 선택하고 설정 저장을 누릅니다. 목록은 서버가 제공합니다.

  5. 원하는 이미지 번역

    이미지에서 오른쪽 클릭 → 이 이미지 번역을 선택하거나 팝업의 이 사이트 번역을 켭니다. 팝업의 원본 보기 / 번역 보기로 화면 표시를 바꿀 수 있습니다.

다른 컴퓨터의 서버에 연결할 때는 그 컴퓨터의 LAN IP와 실제 포트를 입력하세요. 기본 설치 주소 127.0.0.1:8710은 서버 컴퓨터에서만 접속됩니다. LAN 설치 안내에 따라 바인딩 주소와 로그인 비밀번호를 설정해야 합니다.

03 / 시작하기

Linux 서버에 설치합니다.

Python 3.12 이상, uv, 엔진별 의존성을 먼저 준비해야 합니다. 설치기는 사용자 서비스를 만들지만 기본값으로 시작하거나 자동 시작을 켜지 않습니다. 소스 패키지에는 모델·폰트·GPU 엔진이 들어 있지 않습니다.

준비물과 설치 옵션 확인 ↗

로컬 설치 · 기본 127.0.0.1:8710

git clone https://github.com/furyheimdall/comic-translator.git
cd comic-translator
python3 scripts/install.py --engine koharu
systemctl --user start comic-translator

서버 웹 UI에서 사용할 모델을 준비하고 LLM 제공자를 연결한 뒤 원고를 올리세요. 다른 기기에서 접속하려면 로그인 비밀번호가 필요한 LAN 설치 방법을 따르세요.

확장 릴리즈 ↗

번역 권한이 있는 콘텐츠에만 사용하세요. 웹페이지 이미지는 사용자가 설정한 서버로 전송되며, 선택한 LLM 제공자에 따라 글자나 이미지가 외부로 전송될 수 있습니다. LAN의 HTTP는 로그인 정보와 페어링 토큰을 암호화하지 않으므로 신뢰할 수 있는 내부망·VPN·HTTPS를 사용하고 서버를 인터넷에 직접 공개하지 마세요. 확장은 웹페이지 이미지용이며 canvas 전용 뷰어나 브라우저 PDF 뷰어는 처리하지 않습니다. 이 소개 페이지에서는 번역이 실행되지 않습니다.
